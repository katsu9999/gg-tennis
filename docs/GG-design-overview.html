GG — Tennis Court Shuffle

テニスクラブの「今日の割り振り」を自動化。URL一つで iPhone・Android・PC 全対応。名簿から出席者を選ぶだけで、公平でランダム、毎回新鮮なコート割り振りを生成。結果を記録すればランキングも。

v1: Web/PWA（GitHub Pages） v1.5: Android / iOS（Capacitor） クラブ共有（Supabase） RSVP（出欠事前回答） 跨ぎ最適化＋Eloランキング
WHAT IS THIS

このアプリは何？

テニスの集まりで「誰がどのコートに入るか」を毎回考えるのは大変。GG は会員名簿を一度作っておけば、当日は来ている人をタップで選ぶだけ。ボタン一つで割り振りを作り、週をまたいでも顔ぶれが偏らないよう最適化します。

HOW IT WORKS

シャッフルの仕組み（3ステップ）

1

コート構成を決める

人数とコート数から「ダブルス何面・シングルス何面・休憩何人」を計算。ダブルス優先で全員プレーを最大化。

2

休憩する人を選ぶ（公平）

休憩が要るときは、その日プレー回数が多い人から。連続休憩は回避。出番がそろう。

3

組を作る（新鮮・週またぎ）

最近の同組・同対戦ほど避けるよう点数化。同日repeatは最強回避、古い記録は時間で減衰。

例：人数とコートでこう決まる

RSVP

出欠事前回答（誰が来るか分かる）

次回の開催を事前作成して「行く／行かない／未定」を集計。当日「セッション開始」で 「行く」と答えた人を一括で出席化。コート数も予測で決められる。

仕組み（2系統・ハイブリッド）
A
幹事が代理入力

LINE/WhatsApp で集めた回答を、アプリで一括チェック。最小手数。

B
公開RSVPリンク

セッションごとに /rsvp/abc123 のURLを発行。チャットに貼ると各自タップで回答。

C
当日に昇格

「セッション開始」で planned → ongoing。「行く」のRSVPが初期出席者として入る。

D
なりすまし軽減

公開リンクは LocalStorageトークンで「自分の回答のみ修正可」。完全防止は v1.5 のメンバー認証で。

IDENTITY

名前と番号のしくみ（番号インフレを防ぐ）

駐在員の入れ替わりが多くても番号は増え続けません。コツは「人＝名前（永続）」と「番号＝当日だけの小さいラベル」を分けること。

会員＝名前永続。履歴は名前で残る
→
当日番号 1〜N毎回ランダム抽選・使い回し
→
帰任＝アーカイブ削除せず番号は解放

番号は毎セッション 1〜N に振り直すので常にコンパクト。履歴・ランキングは名前ベースなので、番号を使い回しても混乱しません。

ROADMAP

リリース計画（3ステップ）

最初は Web で素早く全員に届け、次に ストア配信のネイティブApp で「アプリ感」を、最後に 機能拡張。コードは1本、データは1つの Supabase で全段階を共有。

v1 — Web / PWA
A
URL一つで全員アクセス

iPhone/Android/PC・インストール不要。PWA でホーム画面追加可。

B
クラブ共有データ

Supabase で名簿・履歴・ランキングを一元管理。閲覧=全員／編集=幹事。

C
機能フルセット

名簿・RSVP・出席・抽選・割り振り・結果記録・3種ランキング（シーズン制）・履歴。

D
RSVP（出欠事前）

次回を作成→admin入力 or 公開リンクで回答収集→当日「行く」を一括出席化。

E
オフライン耐性

屋外で電波弱くてもキャッシュで動く。復帰時に自動同期。

v1.5 — ネイティブApp（Android / iOS）
A
Capacitorでラップ

同じコードを APK / IPA 化。再実装ゼロ。

B
Google Play / App Store 配信

クラブ非会員も検索で見つけられる。アプリ感あり。

C
輝度MAX自動

Webでできなかった屋外モードがフル動作。

D
Web版も並行維持

URL派 と App派が両立。データは同じ Supabase。

v2 — 機能拡張
A
詳細スコア・得失点

ゲーム数入力で深いランキング。

B
実力均衡マッチング

Eloを割り振りに反映、強弱を散らす。

C
殿堂・RSVPリマインドPush通知

歴代シーズン王者、未回答者へのPush通知（Capacitor）。

D
メンバー個人認証

各自マジックリンクでログイン。RSVPなりすまし完全防止＋個人の出席率閲覧。

E
マルチクラブ

1インスタンスで複数クラブ。クラブ単位の権限分離。

TECH NOTES

技術メモ（参考）

🌐

HTML/TS + Vite

素のWeb。GitHub Pages で無料配信。デプロイは push のみ。

🧠

純TSエンジン

割り振り・Eloをロジック分離。フレームワーク非依存・決定的にテスト。

☁️

Supabase

Postgres + Auth + Realtime。クラブ全体で共有。閲覧=全員／編集=幹事（RLS）。

💾

IndexedDB + Outbox

オフライン時はキャッシュで操作、復帰時に同期。

📱

v1.5: Capacitor

同じコードを APK / IPA 化。App Store / Google Play 配信。

✅

TDD・80%+

Vitest で均等性・多様性・Elo・保存・RLSを自動検証。

※ 運用コストは月額0円（GitHub Pages・Supabase ともに無料枠で完結）。クラブ規模なら 10年使っても無料枠の数%以下。v1.5 でストア配信時のみ初期費用（Apple $99/年、Google $25 一度きり）。
